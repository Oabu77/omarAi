Delete local Omar AI data

Android v0.1.0 local-first foundation · Proposed publisher: DarCloud LLC

No Omar AI account exists in this release. There is no remote DarCloud account record or AI-service upload to delete. This staged page still requires contact approval before public hosting.

Delete supported records in the app

  1. Open Omar AI.
  2. Open Settings.
  3. Choose Privacy & data.
  4. Choose Delete local data and confirm.

This removes the local database records named by the confirmation screen—CRM records, conversations, tasks, audit events, and saved output reports—and clears Omar AI camera-preview cache files and any legacy persisted picker grants. It does not delete an original photo or document stored outside Omar AI.

Remove all app-private data

To remove all Omar AI app-private storage, including temporary cache, use Android Settings → Apps → Omar AI → Storage → Clear storage, or uninstall Omar AI. Android menu wording varies by device. Uninstalling also releases app access to selected documents.

Export first if needed

Before deletion, use Settings → Privacy & data → Export local data to write a JSON copy of supported local records to a location you choose. Export does not include every transient cache item.

Remote deletion requests

No web form is required for this no-account build because it creates no Omar AI account and sends no data to a DarCloud backend. If a later version adds accounts, this page and the app must be replaced with working in-app and public account-deletion request flows before that version is released.
